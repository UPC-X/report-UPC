# Recursos de referencia visual

Estas láminas se conservan como material de referencia del informe:

- [Paleta de color](color-palette.png).
- [Iconografía](iconography.png).
- [Espaciado](spacing.png).
- [Tipografía](typography.png).

La especificación vigente está en la [sección 4.1 del informe](../../README.md#41-style-guidelines). La lámina tipográfica muestra Inter y SF Pro, mientras que el texto distingue Plus Jakarta Sans para títulos e Inter para cuerpo. La lámina de espaciado propone múltiplos de 8 px; el texto también documenta separaciones de 12 y 20 px y un margen de 22 px. Esas diferencias quedan pendientes de reconciliación antes de presentar las láminas como especificación de la implementación. Estos recursos no se contabilizan como capturas de pruebas ni como validación con usuarios.
